# NaEstica Barber

Site de apresentação de uma barbearia, desenvolvido a partir de um desafio proposto por um colega. O projeto reúne informações sobre o estabelecimento, cortes, localização e canais de contato.

## Demonstração

[Visitar site](https://naesticabarber.vercel.app/)

![Página principal da barbearia](https://github.com/olegariobru/naesticabarber/assets/50889311/2842b9af-70a3-4c4f-a1fd-d1a9253c86f4)

![Apresentação em dispositivo móvel](https://github.com/olegariobru/naesticabarber/assets/50889311/53f95e4e-b1c8-4d5b-b590-9ee8f6983644)

## Funcionalidades

- Navegação entre apresentação, informações, cortes, localização e contato.
- Alteração do contexto da página por eventos JavaScript.
- Links para WhatsApp e Instagram.
- Estilos adaptados para apresentação em dispositivos móveis.

## Tecnologias

HTML, CSS e JavaScript. O projeto é estático e não utiliza backend nem instalação de dependências npm.

## Como executar

```bash
git clone https://github.com/olegariobru/naesticabarber.git
cd naesticabarber
```

Abra `index.html` no navegador ou utilize um servidor local, como a extensão Live Server do VS Code.

## Organização

- `index.html`: estrutura da página.
- `main.js`: eventos de navegação.
- `estilos.css` e `styles/`: estilos e seções visuais.

## Verificação

Navegue pelas cinco seções, confira os links de contato e a localização. Teste também a apresentação em diferentes larguras de tela. O repositório não possui testes automatizados.

## Aprendizados

Manipulação do DOM, eventos, organização de estilos e adaptação de uma página às necessidades de um estabelecimento.
